## 🚀 サービス概要

5×5グリッドの小さな盤面で、自都市1つ・CPU都市1つが資源とテックツリーを競うターン制ミニゲームです。

## 📝 機能一覧

- 盤面表示（5×5グリッド、自都市／CPU都市の表示）

- ターン進行
- テックツリー（3種）
- CPU簡易AI
- 勝敗判定（全テック解放 or 一定資源到達）

## 🛠 使用技術・選定理由

- Vite（Vanilla JS）＋ Tailwind CSS v4
- 選定理由：GitHub Pagesでの無料公開・軽量さと、Tailwindによるデザイン性を両立するため

## ⚙️ 開発環境・構築手順

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド
npm run lint     # ESLintチェック
npm run format   # Prettier整形
npm run test     # Vitestによるユニットテスト
```
